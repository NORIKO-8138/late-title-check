- 대시보드: https://noriko-8138.github.io/late-title-check/
- 분석 코드: https://kdt-gitlab.elice.io/aba_track/class_04/aba4_project1/team2/darae-project1
- ABA4 1차 개인 프로젝트. 넷플릭스와 무관한 개인 분석이다. This product uses the TMDB API but is not endorsed or certified by TMDB.
